# Elixir Hour

A cosy conversation game — *Coffee Talk*, in the Clash Royale universe.

You play **Sage**, the neutral keeper of a small bar on the Blue/Red border. Over three Nights you brew Elixir drinks (Clash spells as mixers), listen to the regulars — Knight, Wizard, Princess, P.E.K.K.A, Hog Rider — and keep the peace on neutral ground.

## Status

Early prototype, in active development. See [PLAN.md](PLAN.md) for milestone progress.

## Running it

Phase 1 is a single-page web prototype: plain HTML + CSS + JavaScript, no build step. Once the skeleton lands (Milestone 1), open `index.html` in a browser. Reference resolution is 1280×720 (16:9), fully responsive down to mobile.

## Structure

- `src/` — game logic, rendering, UI (no content hard-coded here)
- `data/` — dialogue, characters, recipes, Herald editions, Ledger entries
- `strings/` — string tables for all player-facing text (English populated; KO/JA/DE/ES/FR/PT scaffolded)
- `assets/` — art (characters, scenes, UI, logo) and audio
